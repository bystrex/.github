<h1 align="center">Быстрикс · Bystrix</h1>

<p align="center"><b>Универсальная CMS на Rust. Один бинарник — и больше ничего.</b><br>
Корпоративные сайты, порталы, каталоги и интернет-магазины. Веб-сервер, база, поиск, кэш, шаблоны и плагины в одном процессе.</p>
